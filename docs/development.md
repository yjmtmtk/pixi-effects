# Changing the library itself

The real tests are the **test films** in `tests/films/` (`npm run test:films`; what each group guarantees and what is still to do is `tests/films/COVERAGE.md`); the tests whose subject is the site are in `tests/site/` (`npm run test:site`); no library test uses a site page. `npm install`, `npm run build`, then test in the order of cost: `npm run test:fast` (units, about 20 s), `npm run test:webgl` (every browser test with WebGL drawing, as in a browser without WebGPU; the tests about WebGPU itself are left out), `node scripts/browsers.mjs` (the test films in Chrome, WebKit and Firefox through Playwright, compared: after a change to drawing), `npm run test:changed` (the units plus only the browser tests the changed files need; `-- --dry` says which; anything it does not know runs everything), `npm run release:check` (the whole suite, once, before a release; a release that changes only documents and the version pins since the last tag leaves out the real-browser tests and says so: `npm run release:check -- --scope` shows the decision, `--full` forces everything). To see whether a change altered any picture the repository shows (the site's pages and samples), draw the pages with `node scripts/compare-frames.mjs capture --root <a tree with a built dist/> --pages <list> --out <dir>` for the old and the new tree, and `compare <dirBefore> <dirAfter>` (64 pages in about 70 s with 4 tabs, hashes first, pixels only for the frames that differ; the same build twice already differs by 1/255 on a few pages). After `npm publish`, `npm run post-publish:check` (npm, jsDelivr and only the tests that load the release from the CDN: under a minute). The real-browser tests need Chrome and a built `dist/` (rebuild after changing `src/`); they share one browser per worker, a tab per test (`PE_FRESH_BROWSER=1` starts one per test again). Read `docs/philosophy.md` first: a composition is data; every layer shares one vocabulary; time is deterministic. Docs are generated: `npm run build:ai`.
To try a page against your local build instead of the CDN, point the `pixi-effects*` importmap entries of `skills/pixi-effects/template.html`'s copy at `../../dist/…` (right for a copy in `<repository>/examples/<your-folder>/`).

# 1.0 の凍結表（API を固める前の最後の整理）

2026-11-16。1.0 のあとは名前を変えたり消したりできない。その前に、AI が迷う名前・二通りの書き方・公開しなくてよい内部を片付ける。
材料: `docs/api-surface.txt`（公開面の全部）、DSL のキー表、CLI。3 つの範囲を別々に洗い出し（本体の入口 / レイヤーの DSL / controller・present・3d・CLI）、影響の大きい主張は実物で確かめた。
方針（0.29 と同じ）: 互換の仕組みは入れない。名前を変えたら古い名前は did-you-mean で新しい名前を言う。意味だけが変わるもの（警告できない）は特に慎重に。

**決定済み（この表では扱わない）:** レイヤーの種類（text, shape, …）を残す / scene2d と scene3d は別 / `canvas` を残す / `threeD` の名前 / composition は 1 枚の絵・`clip: true` / マーカー・部品・`frameRate`・`loop` / 変数の書き方 / `mask: { layer, invert }` / 型ごとのアンカー既定（0.29 B6）/ 作者は秒・プレーヤー側はフレーム（0.29 C3）/ 既定の ease は `'none'`。

判断は各行の「案」に ○（案どおり）/ ×（やらない）/ 別案。

## 3. 内部にする（使っているのはテストだけ。壊れるものはほぼない）

- `Movie` の状態を読み取り専用に: `currentFrame` `isPlaying` `totalFrames` `duration` `frameRate` `width` `height` … （`movie.currentFrame = 90` と書けてしまい、シークせずに状態だけ壊れる）。`movie.timeline` は内部に。
- `canvasProblems()` / `canvasReport()`（`review()` が同じことを返す）、`computeEnvelope`（`audioEnvelope` が AudioBuffer も受ける）、`resolveLoader` / `dismissLoader` / `failLoader`（`init({ loader })` がする）。
- 3d の `Scene3DSequence` クラス（約 25 の内部メンバー。scene2d はクラスを出していない）。
- `Controller.options` / `Presenter.options`、`StopImagesOptions.pdf`、`rebuild()` の第 2 引数 `reason`。
- `toggleMute()` は残す（`muted` と同じだが害がない）— 私の判断。

## 4. 足すだけ（壊れない。言われる側が増える）

- **警告の穴を埋める**（実測で 0 件だったもの）:
  - キーフレームの未知のキー: `easing`→`ease`、`delay`/`start`→`at`、`dur`→`duration`、`{ at, x: 50 }`→「`to` か `set` に」。
  - トランジション: 未知の `kind`（`fade`→`crossfade`/`dip`、`push`→`slide`）と、各 kind のキー。今は**何も起きずに消える**。
  - プロパティを種類ごとに確かめる: rect の `fill`→`fillColor`、text の `fillColor`/`color`→`fill`、image の `color`→`tint`（今は通ってしまい何もしない。rect の `fill` は Graphics のメソッドを上書きする）。
  - 未知の形・型: `shape: 'rectangle'` は組み立てで TypeError → did-you-mean。`type: 'rect'`→`type: 'shape', shape: 'rect'`、`group`→`composition`、`sprite`→`image`、`sound`→`audio`。
  - did-you-mean の誤爆を直す（2 文字のキーに何でも当たる: `repeat`→"at" など）。別名: `opacity`→`alpha`、`src`/`url`→`asset`、`muted`→`audio: false`。
  - ルートの大きさ・長さが `init` と composition の 2 か所で食い違ったら警告（0.29 B8 で決めて未実装。今は黙って切れる）。
- **ease**: CSS の `ease` `ease-in` `ease-out` `ease-in-out` を受ける。Penner 名（`easeOutCubic`）に did-you-mean。未知の ease は `'none'` で動かす（今は power1.out で、省略時と違う）。
- **マーカーの行き渡り**: トランジションの `at` の型を `number | Moment` に、stops の `at` も moment を受ける、プリセット（particles 等）は文字列の `at` で throw。
- **アンカー**: text / image / video もトップレベルの `anchorX/Y` を受ける（shape は今も受けている。トップレベル優先）。
- **CLI**: 全サブコマンドで同じ引数の読み方（`--help` は各オプションを出して 0 で終わる、`--flag=value`、did-you-mean）、`pixi-effects --version`、`exports` に `./package.json`。終了コードを契約として書く（0 OK / 1 作品に問題・実行失敗 / 2 コマンドの書き方が違う）。`check --at` も `start` / `end` を受ける。`check x.mp4 --out` に「フォルダを指定」と言う（0.29 D4 の未実装）。
- **report.json を契約に**: `version` を足し、約束するのは `ok` `problems` `files` `exports` `logs` `audio` だけと書く。キー `'sheet 1080x1920'` → `sheet-1080x1920`。

## 5. 1.0 の候補として 1 行だけ（作るかは別に決める）

- キーフレームを速さで書く（`{ to: { x: 900 }, speed: 600 }`: 距離から時間を決める。BetweenAS3 の physical）。
- 動画の `audio: false` を HTML の `muted: true` に（任意）。
- wiggle `{around, amp}` と react `{base, amount}` の名前を揃える（優先度低）。

## 6. 見たうえで、そのままでよいもの（抜粋）

`alpha`（PixiJS/GSAP の言葉。`opacity` は別名で）/ `speed` と `time` / キーフレームの言葉（GSAP どおり）/ `stagger` のオプション（GSAP どおり）/ `snapshot` の `type`・`quality`（`toBlob` どおり）/ `volume`・`muted`・`loop`（`<video>` どおり）/ 列挙値の大小文字（それぞれの出どころに合わせている）/ 音楽の `inst`・`vol`（別名が既に効く。改名は 385 か所）/ `register3D()` と `scene3d()` / scene3d の `root`・`camera`・`view`（PixiJS 3D の名前）/ render が `-o` を確認なしで上書き（作業ループ用）。

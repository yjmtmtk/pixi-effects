# 0.20 マスクの共有・複数 — 設計メモ

状態: 草案。**優先度を下げて保留中**（0.20.0 は「時間リマップ」に変わった: `2026-10-08-time-remap-0.20-design.md`）。実装はまだ始めていない。版番号は、再開するときに振り直す。
読む人: オーナー。決めてほしいことは 7 章。
前提: 0.19.0 まで公開済み。0.19 の設計メモ（5 章）は、0.20.0 に「シェーダー層とマスクの共有」を入れる予定だった。**この版はマスクだけにして、シェーダー層は次の版（0.21.0）に分ける**ことを提案する（7 章の 1）。

## 1. 目的

After Effects の「トラックマット」に当たるものを入れる。いまのマスクは **1 つの層に 1 つ、その層の中に書く**（`mask: { type: 'shape', … }`）。次のことができない。

- **同じマスクを複数の層で使う。** 動くマスク（広がる円、走る帯）を 3 つの層に掛けるには、3 回書き写すしかない。
- **1 つの層に複数のマスクを掛ける**（交差・引き算）。たとえば「円の中で、ただし帯の部分は抜く」。

やらないこと: マスクの羽根（ぼかし）の専用オプション、`threeD` 層へのマスク、シェーダー層（0.21）。

## 2. 確かめた事実

0.19 のときの実験（使い捨ての試作、約 110 行）と、今のコードから分かっていること。

- **1 つの Pixi の `Graphics` を、複数の層のステンシルマスクに使うのは罠。** 最初のフレームは正しいが、マスクが動くだけ（`x`、拡大、回転）で、**最後の層以外が古いマスクのまま**になる。形を描き直すと隠れて見えるので、見つけにくい。画像（`Sprite`）のマスクなら共有できる。
- **引き算（マスク A から B を抜く）は、ステンシルではできない。** 入れ子の反転ステンシルは、外側のマスクの外まで見せてしまう。**テクスチャに描いて、反転した画像マスクにすれば**できる（実験で、生の Pixi でもライブラリでも確かめた）。
- **0.17.0 で、テクスチャ経由の道は既に入っている**（`AlphaMask`）。文字のマスクが長方形になる不具合と、`maskInverted` が外側のマスクからはみ出す不具合は、この道に替えて直した。つまり実験時の見積もり（25〜35 時間）は、この土台がある分だけ小さくなる（計画の段階で見積もり直す）。
- 今のコードの `Composition.ts` は、層ごとに `mask` を読み、マスクを**その層と同じ空間・同じ寿命**で作る。形のマスクは「ステンシル」、文字・反転・画像は「テクスチャ（`AlphaMask`）」。
- 実験の試作が見つけた、本番で要ること: 層の見た目の順序（ラッパーを挟むと、`zIndex`、3D の並べ替え、`layers()`、`inspect` が崩れる）、`inspect` のマスク対応（幅 0 のマットを「サイズなし」と言ってしまう）、警告の数々、文書。

## 3. 設計

### 3.1 書き方

```js
// 名前つきマット: 同じ合成の中の、別の層を名前で指す
{ type: 'shape', shape: 'rect', name: 'wipe', anchorX: 0, width: 0, height: 420,
  initial: { x: 60, y: 300 }, keyframes: [{ at: 0.3, to: { width: 560 }, duration: 1.5 }] },
{ type: 'text', text: 'SHARED', mask: 'wipe' },
{ type: 'text', text: 'MASK', at: 0.2, mask: 'wipe' },

// 複数のマスク（インラインの書き方と名前を混ぜられる）
{ type: 'shape', …, mask: [circleSpec, bandSpec] }                       // 交差（既定）
{ type: 'shape', …, maskMode: 'subtract', mask: [panelSpec, 'hole'] }    // 最初のものから、残りを引く
```

- **名前つきマットの層は、それ自身は描かない。** マットとして使われている名前の層は、画面に出ない。
- **マットの時間は、合成の時間**（そのマット自身の `at` と `duration`）。インラインのマスク（その層の寿命に合わせる）とは違う。名前を指す書き方では、マットを層の外に置くので、そのほうが自然。マットの寿命が、マスクを掛けた層の寿命を覆っていないと、層が見えなくなるので警告する。
- **既存の書き方は、そのまま動く。** インラインの `mask: { … }` と `maskInverted` は変えない。ギャラリーの既存作品は、ピクセルが変わらないこと。
- `maskMode` は `'intersect'`（既定）と `'subtract'` の 2 つ。**`'add'` は入れない**（合成層をマスクにすれば、今でも足し算ができる）。

### 3.2 仕組み

- **名前つきマットは、テクスチャのマットにする。** マットを、合成と同じ大きさのテクスチャに**フレームごとに 1 回**描き、そのテクスチャを、マスクを掛けた全部の層で共有する（`AlphaMask`、0.17 で入った道）。ステンシルのコピーを層ごとに作る案（実験の試作）より、3 つの層に掛けるとき描画が少なく、`Graphics` を共有する罠にも当たらない。縁が柔らかくなる（アンチエイリアス）のも自然。
- **交差**は、マスクの入れ子（層を包むコンテナに 1 つ目、層に 2 つ目…）。**引き算**は、引かれる側を 1 つのテクスチャに描いて、反転したマスクにする（実験で確かめた方法）。
- インラインの形のマスク（今のステンシル）は、そのまま。速さも絵も変わらない。
- 層の順序は、ラッパーを層と同じ位置に置いて保つ（実験の試作は位置を保てていなかった。本番で直す）。

### 3.3 できないこと・警告（すべて「警告を出して、無視」）
名前が見つからない（did-you-mean つき）、同じ名前の層が複数ある、マットの寿命が足りない、`maskInverted` をリストと一緒に使った（`maskMode: 'subtract'` を案内する）、`maskMode` を単独のマスクに使った、マットが `threeD`、マットが別の合成にある、マット自身にマスクがある、マスクを掛けた層が `parent` を持つ（マットは合成の空間にあるのに、層は null 層の空間にあるので、座標がずれる。null 層にマスクを掛けるよう案内する）、`threeD` の層にマスクを掛けた（今も未対応）。

### 3.4 `inspect`、タイムライン

- マットとして使われる層は、レイアウトの検査（「サイズなし」「重なり」「画面外」）から外す。
- マスクを掛けた層の範囲は、名前つきマットでも、マットで切った範囲にする（今のインラインと同じ）。
- タイムライン図では、マットの行に「matte」と表示する（任意）。

## 4. テスト

- **シークの同一性**（前向き・ジャンプ・後ろ向き）: 動く名前つきマットを 3 つの層で共有したとき、3 つとも同じ動きをし、マットが動くだけのフレームでも古いままにならない。
- 引き算・交差の結果の画素（既知の形で、中の点が見える／見えない）。文字・画像・動画のマット。マットの寿命と層の寿命の食い違い。
- **ギャラリー 41 作品とガイドの例が、ピクセルも警告も変わらない**（インラインのマスクを使う `ma`、`liquid-flow-title` など）。前後でポスターのフレームを比べる。
- 警告の各種（3.3 のすべて）、`inspect` がマットを外すこと。
- 速さ: 名前つきマットを 3 つの層で共有したときと、インラインのマスクを 3 つ書いたときのフレームの時間を測って、文書に書く。

## 5. 手順（計画の骨子）

1. データの形と警告（型、名前の解決、`lintKeys` の表に `maskMode`、警告 3.3）。
2. マットの層を描かない、`inspect` が外す。
3. 名前つきマットの共有テクスチャ（1 つの名前を複数の層で）。
4. 複数マスクの交差。
5. 引き算。
6. 文書、レシピ、ガイド、見せ場の作品 1 本（共有マットで文字や写真を抜く）、CHANGELOG。

## 6. リスク

- **テクスチャのマットは、合成と同じ大きさのテクスチャを使う**（1080p で約 8 MB、マット 1 つにつき）。マットが多い作品ではメモリが要る。数を測って文書に書く。
- ステンシルより、テクスチャのほうが縁の見た目がわずかに違う（柔らかい）。名前つきマットは新しい書き方なので、既存作品には影響しない。
- 層の順序とラッパー: 実験が見つけた罠。順序を保つテストを書く。
- `parent` を持つ層への名前つきマット: 当面は警告して無視（3.3）。需要があれば後で広げる。

## 7. 決めてほしいこと（私の推し付き）

1. **0.20.0 をマスクだけにして、シェーダー層は 0.21.0 に分ける**（推し）か、一緒に 0.20.0 に入れるか。
2. **名前つきマットは、共有テクスチャの方式にする**（推し。3.2）か、層ごとのステンシルのコピー（実験の試作）にするか。
3. **マットの時間は合成の時間**（推し。3.1）。
4. **`'add'` は入れない**（推し）。
5. **`parent` を持つ層への名前つきマットは、当面は警告して無視**（推し）。
6. `threeD` 層へのマスクは、**今回も入れない**（推し）。
7. **見せ場の作品を 1 本付ける**（推し）。

## E. 変数（ロードマップの次の機能）のための予約 — 前の案を訂正

前に「`$name` を予約する」と書いたが、**取り下げる**。理由: ① 式のパーサーは `$` を今は受け付けない（予約しても得がない）、② 文字列には金額として `$5` が普通に現れる（`text: '$5'`）。

代わりの案:
- **数値の式**では、宣言した変数を**そのまま識別子として**参照する（`vars: { shift: 0 }` → `x: 'W/2 + shift'`）。
- **文字列・色**では、すでにある `{value}` の置換と同じ形 `{name}` を使う（`text: '{title}'`, `fillColor: '{accent}'`）。色や字体名に `{ }` は現れないので紛れない。
- 予約語（変数の名前にできない）: 式の識別子 `w h W H GW GH t d T contain cover` と関数名（`sin cos … rand noise lerp clamp smoothstep mod step PI`）。宣言の時点で lint が言う。

# 0.25 描画の自由度（シェーダー層、歪み）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `{ type: 'shader', fragment }`（Shadertoy の `mainImage`、`uniforms`、キーフレーム）を層として足し、層の絵を波や陽炎で歪める `warp` フィルタを足す。使わない作品は、絵もコストも警告も変わらない。

**Architecture:** シェーダー層は `three` 層と同じ型（`awaitFrameAt(local)` が毎フレーム呼ばれ、キャンバスのテクスチャを更新するスプライト）。違いは、**ページ全体で WebGL2 のコンテキストを 1 つ共有**して、層ごとの 2D キャンバスにコピーすること（Chrome の約 16 個の制限を避ける）。静的な検査・宣言の生成・エラーの整形は Pixi も DOM も使わない純粋関数（`src/core/shaderChecks.ts`）。`warp` は 2 言語（GLSL + WGSL）の自前のフィルタで、時間を受け取る `TimeFilter`（`grain` と同じ作法）。

**Tech Stack:** TypeScript、PixiJS v8.22（`Sprite` / `Texture.from(canvas)` / `Filter` / `GlProgram` / `GpuProgram`）、WebGL2（共有コンテキスト）、GSAP、vitest（単体は `tests/space/mockPixi.ts`、実ブラウザは `ai/tools/check.mjs` の `serve` と `tests/support/browser.ts` の `launchPage`）。

**Spec:** `docs/superpowers/specs/2026-10-09-shader-0.25-design.md`（オーナーが「23, 24, 25。推しで進めて」と指示。8 章の 7 つは推しのとおり）

**試作の置き場（写し元）:** `docs/superpowers/spikes-0.23-0.25/shader/`（`Shader.ts`、`shader.html`、`shaderspike.test.ts`、`results.txt`）。意味を写す。試作から変える点: (1) 検査・宣言・エラーの整形を純粋関数に切り出して先にテストする、(2) 共有コンテキストを `src/core/glShared.ts` に切り出し、**喪失（`webglcontextlost`）から作り直す**、(3) `uniforms` を宣言し、キーフレームで動かす（`pathRouters`）、(4) `width` / `height` に式、`resolution`、(5) 層ごとの 2D キャンバスは寸法を毎フレーム変えない（共有キャンバスの寸法は層が変わるときだけ変える）、(6) 破棄（プログラム、キャンバス、テクスチャ）。

```ts
export interface ShaderSequenceSpec extends SequenceCommon {
  type: 'shader';
  /** A Shadertoy fragment shader: write `void mainImage(out vec4 fragColor, in vec2 fragCoord)` (GLSL ES 3.00). `iResolution`, `iTime` (this layer's own seconds) and `iFrame` are declared for you, and so is every name in `uniforms`. */
  fragment: string;
  /** Numbers (`float`), arrays of 2–4 numbers (`vec2` … `vec4`) and colours (`'#ff8040'` → `vec3`), animated with keyframes as `'uniforms.speed'` (a component of a vector or a colour: `'uniforms.tint.0'`). */
  uniforms?: Record<string, number | number[] | string>;
  /** Layer size in px (expressions allowed). Default: the composition's size. */
  width?: number | string;
  height?: number | string;
  /** Draw at this fraction of the layer size and scale up (0.5 = a quarter of the pixels). Default 1. */
  resolution?: number;
  /** `true`: the shader's alpha is used (premultiplied). Default `false`: opaque. */
  transparent?: boolean;
}
```

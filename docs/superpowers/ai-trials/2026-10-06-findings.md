# AI authoring trials — 2026-10-06

Six fresh AI sessions (no prior knowledge of the library; only README, docs, examples and `dist/*.d.ts`) each built one piece:
`kinetic` (kinetic typography), `lowerthird` (broadcast package), `slideshow` (Ken Burns + transitions + BGM), `depth` (2.5D showcase),
`threetitle` (three.js title + MP4 export), `barchart` (data-driven chart). All six finished; **none of them saw a single library
warning** — including the ones whose keyframes were silently doing nothing. The condensed findings below were consolidated into
`ai/reference/pitfalls.md`, the fixes in 0.3.0 (see CHANGELOG), and the warnings that now exist.

Not reproduced / unresolved: the barchart session reported a text `fill` keyframe running on absolute time while other props ran
sequence-relative, and a bar tween ~1 frame ahead of its own easing. A direct test showed fill and alpha used the same (composition-time)
origin — the same root cause as the keyframe `at` bug fixed in 0.3.0. The 1-frame drift was not investigated.

# Trial findings (consolidation scratch; source: subagent reports)

## threetitle (works; mp4 export 651,591 B / ~6.05 s; no library warnings)
- DOCS-GAP: "metallic" needs an environment map. metalness 1 + lights only = near black. ctx.renderer is a normal WebGLRenderer -> PMREMGenerator(ctx.renderer).fromScene(...).texture on ctx.scene.environment works. 'three/addons' not in importmap. => tip + recipe.
- FEATURE GAP: no gradient fill / vignette in shape DSL. Agent hand-rolled canvas radial gradient -> data URL asset -> image sequence (only found via 04-media.html gradientDataUrl()). => document recipe (or add gradient fill / vignette preset).
- SPEC-ODD: shape `anchorX/anchorY` are SPEC-LEVEL fields (next to width/height) while text/image/three use `initial.anchorX`. Agent hesitated; unknown whether initial.anchorX works for shapes (candidate: accept both or warn). VERIFY in src.
- MY-MISTAKE: three layer sized to full canvas -> small knot + text collision. Tip: size the three layer to the region you want; camera z ~5.4 for torus knot (1,0.32) at fov 50; clipped at layer rect.
- DOCS-GAP minor: Controller overlay bar covers the bottom of the canvas in screenshots but is NOT in exported video. Note it.
- DOCS-GAP minor: no documented render-time API (wrap performance.now(), count 'progress' events).
- Tooling: agent-browser screenshot needs ABSOLUTE paths.

## lowerthird (works; 2 edit cycles; no library warnings)
- FEATURE GAP (also in threetitle): no gradient fill (linear/radial). Hand-rolled 36 stacked rect bands + 16 alpha circles (6 circles @ .035 looked banded; needed 16 @ .013). => gradient fill / glow primitive or documented recipe + "no gradients" tip.
- DOCS-WRONG-ish (also in threetitle): shape anchorX/anchorY are TOP-LEVEL (next to width/height); easy to put in `initial` by mistake. Mask prose says "give the mask anchorX:0" without saying where. Also defaults differ: shapes centre-anchored, text top-left, undocumented defaults table.
- DOCS-GAP: mask lives in the PARENT's coordinate space and does NOT move with the maskee (slide content, keep mask static).
- SPEC-ODD mild: exit wipe needs x and width tweened together; no mask direction/reverse. Agent wrote wipeMask() helper => candidate preset.
- DOCS-GAP: composition scale/rotation pivot: pivotX/Y + x/y = world position of the pivot point; only documented for 3D.
- FEATURE GAP: text width not available in expression scope (w is "video intrinsic"); ticker end x guessed (-1900). Unknown if '-w' works for text -> VERIFY (scope w for text = text.width at build; per Scope.ts intrinsicWidth set in Text.build => likely works).
- FEATURE GAP: no repeat/yoyo for keyframes (pulse made via JS loop of N keyframes).
- Tooling: Controller overlay (.movie-controller) covers bottom ~50px in screenshots and looked like a rendering bug. => harness: hide it / `new Controller` optional in template; document.
- Tips: DSL is plain objects -> use JS helpers/loops; nested composition for grouped scale/pulse; negative `at` for outros; rotation in degrees.

## slideshow (works; mp4 render ok; audio fades verified by decoding render output; no library warnings)
- LIB/SPEC (silent no-op!): audio asset (bgm.mp3 = 6.0 s) shorter than sequence duration WITHOUT `loop` silently goes quiet. Found only by decoding the rendered mp4. => WARN when an audio asset is shorter than the sequence duration (unless loop); doc tip.
- DOCS-GAP: transition timing formula: transition sits at the next sequence's `at`; sequences overlap by T; total = n*STEP + T, STEP = L - T. One-line formula in Transitions docs. (Candidate: helper to lay out scenes with overlaps.)
- DOCS-GAP: transitions combine fine with kenBurns (zoom + kenBurns scale composes); not stated.
- DOCS-GAP: transitions only affect the named from/to sequences; other top-level layers (captions) stay put. State explicitly.
- SPEC-ODD: zoom default ease linear; power2.out makes the incoming scene ~opaque by 40% -> looks like a cut. Doc: which ease suits which transition.
- DOCS-GAP: kenBurns image is cover-fitted; source images should be >= canvas resolution (use 1920x1080 for 1280x720).
- DOCS-GAP: no way to sanity-check audio without rendering (trick: movie.render() + decodeAudioData). Maybe movie.getAudioBuffer() exists as `movie.audioBuffer`? VERIFY (Movie has audioBuffer field).
- FEATURE GAP: captions tied to slide (computed at(i)+1 by hand) -> `caption` on kenBurns or `at` relative to a named sequence; audio fade helper (withFade for audio).
- Tooling: Controller bar covers bottom ~60px (3rd agent to hit it) -> README/template/skill note.
- Generated assets: canvas.toDataURL() as `src` works (example 08).

## depth (works; ~20 checkpoints, 4 cycles; no library warnings)
- DOCS-GAP / FEATURE GAP: camera ORBIT (circular path) not documented/possible: hand-sampled 80 keyframes (0.1s, ease 'none') computing x=cx+R sin(th), z=R cos(th). => `orbit` helper/preset (spec->spec) + recipe. Also combined orbit+dolly-zoom needs explicit z = (H/2)/tan(fov/2) computed by hand (auto-z only if z never set).
- FEATURE GAP: expression language is BUILD-TIME only (no per-frame `t`), so curves must be sampled. Repeat/yoyo keyframes missing (bob made from 3 consecutive `to`). No group/null layer for parenting 5 cards under one transform. No particle emitter (46 seeded circles by JS).
- MY-MISTAKE / TIP (key): under a dolly zoom only z=0 stays fixed; everything with z>0 balloons (headline at z=120 clipped). Keep headline at z=0, near cards z<=~70; keep every layer at z < camera distance or it vanishes (silently!). => WARN when a threeD layer is hidden for being behind the camera plane; doc tip.
- TIP: CTA / final overlay as a plain 2D layer (no threeD): ignores camera, screen-aligned, on top by stack order. Near threeD layers sort on top of text (z-sort) -> relayout.
- DOCS-GAP minor: `from` (alpha,z,rotationY) entrance on a threeD composition works but only `to` shown in example; alpha on threeD nested composition works.
- DOCS-GAP: text style `padding`, `dropShadow`, `letterSpacing` and `filterArea` (shape-local space!) used in 12-title-motion are NOT in dsl.md; agent copied from the example.
- Tooling: screenshot needs absolute path (2nd time).

## kinetic (works; ~30 frames; no library warnings even while keyframes were silently no-ops)
- **SPEC (biggest, 4 debug cycles, SILENT)**: keyframe `at` is measured from the PARENT composition's t=0, NOT from the sequence's own `at`. Sequence at:2 with keyframe at:0 -> keyframe plays at parent t=0 (before the sequence is even visible) -> only end state shows, `from` skipped. Agent expected AE-like / layer-local. Also NEGATIVE at is resolved with the sequence's duration but offset by parent only (not +seq.at) -> wrong for at>0 sequences (VERIFY in src/sequences/Base.ts + Timeline.resolveAt). => DECISION CANDIDATE: make keyframe `at` sequence-local (breaking; update presets, Transitions macro, examples, Image/Shape/Text/Audio custom bind paths) + lint "keyframe starts after sequence end".
- DOCS-WRONG: dsl.md nested-composition example uses `rotation: -0.2` (reads as radians) but 2D rotation is DEGREES. State units for 2D rotation (and fix the example).
- SPEC-ODD/DOCS-GAP: sequences are not removed after `duration`; they hold end state and only `renderable` toggles; z-order = array order. Scenes built by stacking full-screen rects. State explicitly.
- MY-MISTAKE tips: flood circle with expo.in stays tiny until the end (use power2.in, bigger radius); lifespans must overlap the transition layer; text anchor 0.5 centres the line box not cap height; Arial Black ~0.8*fontSize per glyph, leave ~7% for hold-scale.
- DOCS-GAP: shape scale vs anchorX/Y interaction not stated; no text wordWrap / measured width in scope / per-letter control; no blend modes (screen/add) for flashes.
- Tooling: keep the template's try/catch around init; Controller bar overlays screenshots (auto-hides only on pointer idle); absolute screenshot paths (3rd time).
- Recipe that worked: slam = from {scale 2.6, rotation -5} to {scale 1, rotation 0} 0.16s expo.out + white rect alpha .8->0 over .28s on the beat.

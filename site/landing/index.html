Video, written as data.

pixi-effects turns a tree of plain objects — text, shapes, images, keyframes, a camera, sound — into motion graphics. The same data plays in the browser, scrubs frame by frame, and exports MP4 with no server. Written by you, or by an AI that can check its own work.

The complete minimal composition, as JavaScript. The play button on the right runs this very text in your browser:

import { Movie, kenBurns } from 'pixi-effects';
const movie = new Movie();
await movie.init({
  canvas, width: 1280, height: 720, duration: 6, frameRate: 30,
  background: '#0a0a0f',
  composition: { sequences: [
    { type: 'text', text: 'Hello', at: 0.5,
      style: { fontSize: 120, fontWeight: 'bold', fill: '#fff' },
      initial: { x: 'GW/2', y: 'GH/2', anchorX: 0.5, anchorY: 0.5 },
      keyframes: [{ at: 0, from: { alpha: 0, y: 'GH/2 + 40' },
                    to: { alpha: 1, y: 'GH/2' },
                    duration: 0.6, ease: 'power2.out' }] },
    { type: 'audio', sfx: 'chime', at: 1.1 },
  ] },
});
movie.play();
// or: const mp4 = await movie.render({ format: 'mp4' })

01

Start with one sentence

You do not have to learn the library. Tell any AI this one sentence and it understands and gets to work: the repository's first screen tells an AI where to go, and the library checks what it makes.

the sentencetap an ending to swap it, then copy

Use https://github.com/yjmtmtk/pixi-effects to make a video: a 10-second title for a bakery, warm cream colours, a soft chime at the end

Endings

1 · the AI opens the repository

Its first screen says where to go

The top of the README, AGENTS.md and ai/SKILL.md tell an AI with a shell what to read and what to skip (“do not read the whole repository”). An AI in a browser chat with no shell is sent to ai/CHAT.md instead.

2 · it writes, then checks

One HTML file of plain data

The video is a tree of plain objects in one file that loads the library from a CDN. The AI runs npx pixi-effects-check: the warnings say what to change, and the tool writes a contact sheet the AI looks at before it says it is done. In a chat, the page itself shows the warnings in a red box.

3 · you watch it

Open the file, press download

Open the file in a browser, watch it, and press the download button in the player bar for the MP4 — or the AI renders it with one command, npx pixi-effects-render your-video.html -o your-video.mp4.

Works inChatGPT, Claude in a browser, Codex, Cursor, Claude Code — any AI that can open a link.

  • The AI has to be able to read a web page: it fetches the repository, and in a chat, ai/CHAT.md.
  • In a chat with no preview window you save the file it gives you and open it in a browser.
  • It is a young library, and the first try may need a couple of rounds: if a red box appears, paste back what it says — each message names what to change.
  • The check can tell the AI that nothing is broken, not that the video is good. That judgement is still yours.
02

What you get

One vocabulary for every layer: at / duration / initial / keyframes / filters / mask. Repeated structure is a JS loop that returns objects. Any number can be an expression string like 'GW/2'. Same data, same video — seeded, no wall clock, and the preview equals the export.

composition

Write it as data

A tree of plain objects: text, shapes, images, video, audio and nested compositions, each with at, duration, initial, keyframes, filters, mask. Numbers may be expressions ('min(W,H)*0.4'). Deterministic and seeded, so the file you export is the frame you saw.

export

Runs in the browser, exports MP4

Play, scrub and export MP4 / WebM / MOV with no server — WebCodecs via mediabunny. A starter is one HTML file with an import map; npm install works too. Headless from a script: npx pixi-effects-render page.html -o out.mp4 (Node 22 and Chrome).

  • Documented: Chrome 94+, Edge 94+, Safari 16.4+, Firefox 130+. Verified by the author in Chrome; Safari and Firefox are documented, not independently verified.

camera

2.5D camera, After Effects layers

Layers, keyframes, expressions, masks, blend modes, nested compositions. Add threeD, z, rotationX/Y and a camera layer for parallax, dolly zooms, orbits and cameraPath() flights. An optional real three.js layer when you need it.

motion

Text, particles, morphing, motion blur

animateText per letter, word or line; wiggle, stagger, followPath, path morphing, draw-on strokes (trimEnd), particles() — all seeded and baked into keyframes. True motion blur at export by sub-frame averaging.

  • Filters by name, no import: blur noise alpha colorMatrix plus the 38 filters of pixi-filters (glow dropShadow crt rgbSplit oldFilm glitch pixelate twist …). Seven transitions, chroma key.

audio

Sound with no audio files

sfx: 11 synthesised presets (click, pop, swoosh, riser, hit, chime …) or your own voices. Music written as text: notes, chords and drum patterns as strings — 8 instruments, 10 drums, swing, fades, tempo changes, loop. Deterministic, and in the exported file at the same moment.

  • Audio-reactive visuals: audioEnvelope(), musicEnvelope(), react(). Hear eight tunes written as text in the music lab.

presenter

Presentations, PDF, a player

deck() and a Presenter: slides that move, with stops, arrow keys / click / swipe, a page overview, a presenter view with notes, and PDF export.

  • A drop-in video-style player (play, scrub, volume, fullscreen, download), themed with one accent colour — or build your own on the movie's events.
03

Written by AI, checked by AI

This is what happens after the one sentence. A model cannot watch its own video, so the library reports back in text it can act on: warnings written as instructions, a contact sheet, a timeline, and a real export decoded again. Most of the gallery was made this way.

1 · write

One HTML file of data

The agent follows the skill (ai/SKILL.md) with a cheatsheet, tested recipes, a pitfalls list and llms.txt / llms-full.txt. The recipes in the docs are executed by the test suite, so they stay true.

2 · check

pixi-effects-check page.html

Opens the page in headless Chrome and reports, with exit code 0 or 1:

  • library warnings, written as instructions with “did you mean”
  • layout problems: text cut off or off-canvas
  • sound problems, via movie.inspectAudio()
  • a contact sheet PNG and a timeline
  • a real export, decoded again

3 · look

Frames and a timeline, as data

movie.inspect(frame), contactSheet() and snapshot() from code; pixi-effects-view page.html opens the page with a zoomable timeline under it, every layer a bar, every keyframe a mark.

4 · fix

Warnings are instructions

Each message names what to change. The agent edits the data, runs the check again, and stops when it exits 0. No GUI in the loop — which is the point when the author is a model.

No shell? A chat is enough.

The one sentence works in a browser chat too; this longer prompt points the model straight at the chat entry. That entry (ai/CHAT.md + ai/chat-template.html) is for ChatGPT or Claude in a browser: the model returns one HTML file that loads the library from one CDN, and the page shows any warnings in a red box for you to paste back. The download button in the player gives you the MP4.

Read https://raw.githubusercontent.com/yjmtmtk/pixi-effects/main/ai/CHAT.md and follow it. Make a 10-second 1280×720 title video for … (what you see, the colours, what you hear). Give me the whole HTML file.

05

Next to Remotion and fframes

Three different answers to “video from code”. Remotion is the mature one, fframes is the fast native one, pixi-effects is the one where the video is data and a model can check it. None of them is better overall; pick by what you are making and who is writing it.

Checked 2026-10-07, from their own pages: remotion.dev · fframes.studio and its repository. No benchmark of pixi-effects against either has been made.

 pixi-effectsRemotionfframes
How a video is written A tree of plain objects (JSON-shaped) with keyframes and expression strings; JS loops for repetition. No per-frame code. React components. Three ways to work: agentically, interactively (drag-and-drop in Remotion Studio), or programmatically. Rust and SVG.
Where it runs, what you install Entirely in the browser: one HTML file with an import map, or npm install pixi-effects pixi.js gsap. Headless render needs Node 22 and Chrome. A React / npm project. Server-side and client-side rendering; Remotion Lambda for cloud rendering. Prebuilt binaries for macOS and Linux (arm64, x86_64); building needs Rust and ffmpeg libraries; Windows needs a separate FFmpeg setup.
Preview and editing A video-style player (play, scrub, export) and a zoomable timeline viewer. No GUI editor. Remotion Studio (interactive, drag-and-drop), a Player component for your own app, an Editor Starter. A real-time GPU preview window and a browser-based editor (WebAssembly) with a timeline.
Rendering WebGL in the browser, encoded with WebCodecs (mediabunny) to MP4 / WebM / MOV; needs a WebCodecs browser. Preview equals export. Not a native GPU renderer; no benchmark made. On the author's laptop a typical 12 s piece exports in about 10 s. Server-side, client-side and batch rendering, plus Remotion Lambda in the cloud. GPU (Skia on Metal or Vulkan), no headless browser, ffmpeg linked in for encoding. Its README says about 10× faster than its own CPU backend and mentions a 128 s video rendered in 36 s.
Sound Synthesised sfx (11 presets) and music written as text, with no audio files; audio-reactive helpers. Checked as numbers by inspectAudio(). Not covered by the pages checked for this comparison. audio analyze: loudness (LUFS), true peak, clipping.
AI-agent workflow A check tool that reports warnings as instructions, layout and sound problems, a contact sheet, a timeline and a decoded export; a skill, llms.txt, and a chat-only entry that needs no shell. 11 agent skills, installed with npx skills add remotion-dev/skills; agents preview their work in Remotion Studio. inspect (missing fonts, text cutoff), audio analyze, and a skill for coding agents via npx skills add.
Licence MIT. Source-available. Free for individuals, non-profits and organisations of up to 3 people; larger for-profit organisations need a Company licence (from $100 / month, usage-based); Enterprise from $500 / month. MIT.
Maturity 0.16.1, experimental, pre-1.0: the API can still change between minor versions. Small ecosystem. About 62,000 GitHub stars (stated on its page). Large ecosystem of React components. Its README says it “stayed unreleased for years” before this release and does not say whether the API is stable.
Best for Motion graphics described as data, written by an AI or by hand, that must play and export in a browser with no server. Teams working in React who want a studio, a player for their app, a large ecosystem and cloud rendering at scale. The fastest native GPU renders, for people at home in Rust and SVG on macOS or Linux.

Choose pixi-effects when…

the video should be data so an AI can write it and a tool can check it; it must play, scrub and export in the browser with no server; you want sound and music with no audio files; you want MIT and a starter that is one HTML file.

Choose Remotion when…

you live in React and want the mature ecosystem: Remotion Studio, a Player component in your product, batch and cloud rendering with Lambda, and a large community. Budget for the Company licence if your for-profit organisation has more than three people.

Choose fframes when…

raw render speed is what matters and you are comfortable in Rust and SVG on macOS or Linux: a native GPU pipeline (Skia on Metal or Vulkan) with no browser in the loop, ffmpeg built in, MIT.

Not pixi-effects when…

you want a GUI editor; you need the React ecosystem or cloud rendering at scale; you need the fastest native GPU renders; you need to edit existing footage (a video layer plays a clip inside a composition, nothing more); or you need an API that will not change before 1.0.

statusv0.16.1experimental · pre-1.0MIT

Honest status. pixi-effects is experimental and pre-1.0: the API can still change between minor versions. There is a timeline viewer but no GUI editor; the ecosystem is small; export needs a WebCodecs browser; it draws with WebGL in a browser rather than a native GPU renderer, and no benchmark against other tools has been made (a 48 s 1080p film with 16-sample motion blur took 99 s to export on the author's laptop). It is not a tool for editing existing footage.

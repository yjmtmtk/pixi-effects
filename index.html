Start in 30 seconds

In Claude Code, Cursor or Codex

Add the skill once:

npx skills add yjmtmtk/pixi-effects

Then ask for a video, in any words. It checks its own work and renders the MP4.

In any chat

Paste one sentence and say what you want:

Use https://github.com/yjmtmtk/pixi-effects to make a video: …

You get one HTML page. Open it: the download button under the video saves the MP4.

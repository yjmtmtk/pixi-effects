    About this reel

    Many pieces, three models, one brief. Each piece was made in its own session by a Claude model (fable, opus or sonnet) that read the same brief and the same docs, then wrote a single HTML file: a composition of text, shapes, images, audio and a 2.5D camera, described as data and played back by pixi-effects. Which model made which piece is in MODELS.md.

    What we learned. Every author kept stumble notes while working: where the docs were unclear, where the library surprised them, what they wished existed. Those notes live in the _notes folder, one file per piece, and are reachable from each piece in the theatre. The stumbles became library fixes, warnings and documentation, so the next author does not trip over the same thing.

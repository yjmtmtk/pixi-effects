Music written as text

Eight tunes, no audio files. Each one is a few lines of text (notes, chords, drum patterns, a tempo) played by the small synthesiser in pixi-effects. Press play; open Score to read what you hear. Seven were written by fresh Claude sessions that had only the notation guide and a one-line brief, and none of them could hear what it wrote.

An audio layer takes the same object: { type: 'audio', music: { bpm, tracks, drums } }. To play it yourself, await musicBuffer(music) returns a Web Audio buffer. How the notation works →

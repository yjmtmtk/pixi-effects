The smallest useful composition: one text sequence that fades in, sits, fades out. Read this first — every later example just stacks more sequences and properties onto this skeleton.

  • Movie.init({ canvas, width, height, duration, frameRate, composition }) — the entry point
  • composition.sequences — the list of things on screen
  • type: 'text' with style (set once) and initial (transform applied before keyframes)
  • keyframes with from/to/at/duration/ease
  • Negative at — measured from the end (e.g. at: -0.5 = 500ms before the composition ends)

02 · keyframes & expressions

A single text moves through every transform property on the timeline. Each segment is one keyframe that exercises a different feature so you can see which knob does what.

  • PIXI shorthands: scale, rotation (degrees), skewX, tint
  • Easing — back.out, elastic.out, power2, sine.inOut
  • Expression scope: GW/GH (root size), min(...), arithmetic
  • Mutually-exclusive keyframe forms: from+to (fromTo tween), to (continue from current), set (instantaneous)
  • Negative at for the closing fade-out

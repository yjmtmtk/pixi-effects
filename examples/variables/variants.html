The film is written once. The words are {head} {sub} {tag} {price}, the colours {accent} {paper} {ink}. A language or brand switch builds the pictures again at the same frame and reuses the mixed sound (audio: reused). The format switch hands rebuild() a new layout and a new size. The same file renders as a variant from the command line: pixi-effects render variants.html --var accent=#2b7fff.

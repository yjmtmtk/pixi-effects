11 · depth & camera

2D layers placed in depth and seen through a camera — no three.js. Add threeD: true to a layer, give it z / rotationX / rotationY, and add a { type: 'camera' } layer.

  • z: +z is toward the viewer (bigger, nearer). rotationX/Y: degrees, same signs as CSS.
  • 0–4 s: the camera trucks sideways, so near cards slide faster than far ones (parallax). 1–4 s: the middle card spins.
  • 4.5–7.5 s: only fov animates. z follows it automatically, so the z = 0 plane holds still while depth strength changes (dolly zoom).
  • A card is a nested composition with threeD: true, so shapes and text rotate together.

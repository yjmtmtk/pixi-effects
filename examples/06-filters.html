06 · filters

Built-in chromaKey, PIXI's stock BlurFilter + ColorMatrixFilter, and a couple of community pixi-filters via type: 'custom'. Every filter parameter you can see animating is reached by a 'filters.<name>.<prop>' keyframe path.

  • Filters are per sequence, named, and ordered — order matters (blur then glow ≠ glow then blur)
  • Built-in: { type: 'chromaKey' } — animatable threshold, smoothing, spill
  • Custom: any PIXI Filter instance via { type: 'custom', filter: new XxxFilter() }
  • colorMatrixFilter via ColorMatrixFilter — desaturate, hue rotate, contrast
  • pixi-filters loaded from esm.sh (note: not a dependency, install on your side)

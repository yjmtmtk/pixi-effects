10 · three.js layer

A rotating torus knot rendered by three.js and composited as a normal pixi-effects sequence — the pixi-effects/three entry bridges a three.js scene to a PIXI texture per frame.

  • registerThree() — call once before Movie.init to register the 'three' sequence type
  • three({ type: 'three', setup, ... }) — setup(ctx) builds the scene against ctx.scene / ctx.camera and can return { objects } to expose named objects
  • 'three.<name>.<path>' keyframes — animate any exposed object's property, same from/to/set vocabulary as everything else
  • update(t) must be a pure function of t (sequence-local seconds) — no wall clock, no unseeded randomness — so scrubbing and export render identical frames
  • The layer is a normal sprite once built: 2D initial/keyframe props (alpha, x/y, scale), masks, and filters all work on it

Move the objects drag an object of a 3D scene along a platform: hit.scene3d.grab('floor')

Take an object.

The scene is a scene3d layer (PixiJS 3D) that follows the movie's camera and light (followCamera, followLights), so the shadow is the movie's light's. movie.pick says which object is under the pointer (its label), hit.scene3d.grab('floor') keeps the point that was taken under the pointer while the object slides on the floor (the page stops it at the edge of the platform: a limit that is drawn can be felt), and movie.redraw() draws the frame again. No object is moved by code that knows the camera.
